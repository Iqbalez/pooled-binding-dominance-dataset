# Synthetic Pooled Binding Assay Panels

This repository is the source packet for an original synthetic dataset. `generate_raw.py` makes independent ten-candidate receptor panels. Each panel contains four numeric descriptors per candidate, two pooled calibration mixtures, two bound counts from 200 simulated receptors, an unmeasured query mixture, and the hidden winner for that query. The generator is an idealized one-site competitive equilibrium with panel-specific affinity variation. It is not laboratory, compound, patient, or clinical data.

The Eris challenge **Pooled Binding Dominance Forecast** asks a participant to infer which anonymous candidate is the largest expected occupancy contributor under the query concentrations. The raw upload contains the generated panel records and hidden winner; `prepare.py` creates the participant train/evaluation split. The private master seed is intentionally absent from this repository and from participant files so held-out winners cannot be regenerated by source lookup. A participant can run the generator with a different seed to make development data.

Source file inventory:

- `generate_raw.py`: the exact synthetic data generator (MIT License)
- `DATA_LICENSE.txt`: CC0 1.0 dedication for the generated data and documentation
- `LICENSE-CODE`: MIT License for code
- `GENERATOR_REQUIREMENTS.txt`: the exact NumPy version used for the frozen release
- `README.md`: this source and provenance description
- `FROZEN_MANIFEST.json`: SHA-256 hashes of the delivered raw archive and its seven members

The frozen raw data was generated with CPython 3.12.10 and NumPy 2.5.3. The generator accepts Python 3.10 or later with NumPy, but the pinned environment is recommended for exact replay. Example:

```sh
python generate_raw.py --seed your-own-private-seed-at-least-32-characters --count 100 --out output
```

Original dataset source: https://github.com/Iqbalez/pooled-binding-dominance-dataset . The challenge raw archive is supplied with the dataset upload; this source repository carries the exact generator, licenses, and the frozen raw-archive hash in `FROZEN_MANIFEST.json`. No third-party experimental measurements or code are included.
